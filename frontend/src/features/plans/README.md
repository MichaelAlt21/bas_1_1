# Результаты

`ScheduleChart.tsx` и `schedule.ts` — диаграмма расписания бортов (полеты, обслуживание,
очередь к ЗУ, зарядка); `PlaybackControls.tsx` и `playback.ts` — симуляция; `PlanArchive.tsx` —
архив расчетов. Показатели и таблица вылетов собираются в `app/App.tsx`, маршруты рисует
`features/map/MapWorkspace.tsx`.
