# Готовые карты: решение первой версии

Проверка официальной документации: 17.09.2026.

## Выбор

Используем OpenLayers как движок отображения, а картографические данные берем
у готовых поставщиков. OpenLayers не создает карту мира и сам не предоставляет снимки.

| Подложка | Источник | Ключ | Состояние в проекте |
|---|---|---|---|
| Схема | OpenStreetMap standard tiles | Не требуется | Включена по умолчанию |
| Спутник | MapTiler Hybrid | Требуется | Адаптер подключен, активируется ключом |

Охват — глобальная карта; детальность и актуальность спутниковых изображений зависят
от района и доступного набора данных. Это не съемка в реальном времени. Качество
на конкретном конкурсном участке надо проверить после подключения аккаунта.

## Как включить спутник

1. Создать свой аккаунт на https://cloud.maptiler.com/ и получить API-ключ.
2. Для локального запуска скопировать frontend/.env.example в frontend/.env.local.
3. Записать `VITE_MAPTILER_KEY=...` и перезапустить frontend.
4. Для Compose записать тот же параметр в корневой .env и пересоздать web-контейнер.
5. Выбрать «Спутник с подписями · MapTiler» над картой.

`VITE_`-параметры видны браузеру. Это клиентский ключ, не серверный секрет.
Использовать отдельный ограниченный ключ и настроить разрешенные HTTP origins
в аккаунте, включая адрес разработки и будущий домен. Не записывать ключ в Git.

Настройка идентификатора: `VITE_MAPTILER_SATELLITE_ID=hybrid-v4`.
С 18.09.2026 спутник подключен через Maps API: `/maps/hybrid-v4/256/tiles.json`.
Прежний путь `/tiles/satellite-v4/tiles.json` больше не используется.
Дополнительная схема MapTiler удалена из переключателя; схема OSM сохранена.
Можно заменить идентификаторы согласно своему аккаунту без изменения React.
TileJSON передает URL тайлов, масштабы и атрибуцию. Компонент показывает
атрибуцию постоянно, без скрытия под кнопкой.

Подключение без настоящего ключа не тестировалось на спутниковых снимках.
В программе нет чужого ключа или неофициальных URL тайлов Google/Яндекса.

## Почему этот вариант

Один GIS-движок управляет областью съемки, запретами, площадками и маршрутами,
независимо от подложки. Картографический источник заменяется в providers.ts.
Сценарии и расчетное ядро не зависят от аккаунта поставщика карт.

Схема OSM позволяет сразу запустить прототип без регистрации. Публичный сервер
тайлов OSM имеет ограничения, не дает SLA и не предназначен для массовой выгрузки
или предзагрузки офлайн-карт. Нужны видимая атрибуция и соблюдение правил запросов.
В проекте используются обычные браузерные запросы OpenLayers без bulk download.

Для MapTiler нужен подходящий план с достаточной квотой. Бесплатную регистрацию
не считать обещанием бесплатной эксплуатации: актуальные лимиты, доступность
растрового API, назначение использования и тарификацию проверять для своего аккаунта.
В этой интеграции используются TileJSON/тайлы, поэтому нельзя автоматически
приравнивать их тарификацию к сессиям в другом SDK. Платный тариф не подключался.

## Альтернативы

| Вариант | Что дает | Решение для проекта |
|---|---|---|
| Яндекс Maps JS API 2.1 | Схема, спутник, гибрид | Возможная альтернатива при приоритете российских карт; потребует отдельного адаптера официального SDK и проверки тарифа |
| Google Maps JavaScript API | Roadmap, satellite, hybrid, terrain | Возможная альтернатива; учетная запись, биллинг и условия официального API |
| Собственный сервер тайлов | Контроль доступности | Следующий этап; требуется заранее лицензированный источник данных, особенно снимков |

Не подключать скрытые/неофициальные tile-endpoint Google или Яндекс к OpenLayers.
Смена поставщика через официальный SDK может потребовать смены UI-адаптера карты,
но не модели GeoJSON и не Python-алгоритмов.

Подложка не является источником разрешений воздушного пространства, точного рельефа
или препятствий. Эти слои и источники подключаются отдельно. Нарисованная поверх
спутника линия сама по себе не подтверждает безопасность или выполнимость полета.
