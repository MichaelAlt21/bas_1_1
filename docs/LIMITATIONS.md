# Известные ограничения KUMOsystems 1.1

KUMOsystems — сервис **предварительного** планирования. План — это оценка маршрутов, расписания
и ресурса для решения «сколько бортов, какие вылеты, сколько времени». Он не является заданием
для автопилота и разрешением на полеты. Каждый план перечисляет в предупреждениях допущения,
которые к нему применены.

## Модель местности и воздушного пространства

- Рельеф задается одним диапазоном высот района, без цифровой модели (DEM). Высоты полета —
  над поверхностью (AGL). Высоты зон и препятствий по уровню моря пересчитываются по диапазону
  рельефа в худшую сторону, что на холмистом районе избыточно осторожно.
- Все борта обходят все зоны и препятствия, которые касаются хотя бы одной высоты полета.
- Ограничения ИВП упрощены: потолок 150 м — предупреждение, а не проверка разрешительного
  порядка; NOTAM и данные органов ОВД не подключены.

## Погода и ресурс

- Ветер постоянный во времени и пространстве (Open-Meteo — модельные данные на 10 м);
  порывы проверяются только против предела парка. Прогноза на время работ нет.
- Ресурс — бюджет времени (паспортная длительность × коэффициент × (заряд − резерв)), а не
  энергетическая модель; заряд на площадке линейный, без замедления в конце.
- Норматив ТО Gemini принят по аналогии с 801; время заряда 801 и 201 — настройка.

## Кинематика

- Коптер: мгновенный разгон, вертикальный набор и снижение над площадкой.
- Самолет 201 — демонстрационная модель: постоянный крен без ввода в разворот, постоянная
  воздушная скорость, путь только по дугам Дубинса (облет препятствий между галсами не
  строится: если разворот упирается в ограничение, такой переход недоступен). Радиус,
  скороподъемность, прямой заход, 50 м запуска и высота выпуска парашюта — настраиваемые
  допущения, паспортных данных нет. Самолет стартует и садится только на своей площадке.

## Съемка

- Геометрия кадра — надир, плоская поверхность, номинальный GSD; наклон, смаз, рельеф и
  калибровка не моделируются. Подтвержденные профили камер — RGB (Sony RX1R II, Geoscan PF1B,
  Sony UMC-R10C) и мультиспектральная Geoscan Pollux; для ИК, LiDAR и геофизики ширина захвата
  задается вручную, камера 801 не подтверждена.
- Галсы общие для парка и считаются по самому узкому захвату.

## Алгоритм

- Эвристика: глобальный оптимум не гарантируется, отказ найти план — не доказательство
  невыполнимости. Распределение галсов не учитывает сближения — их разводит расписание
  задержками на земле.
- Эшелоны: одна высота на весь вылет (нет отдельной высоты перелета); автоматически поднимаются
  только коптеры; уровни только вверх от высоты съемки; интервал 20 м — значение по умолчанию,
  а не норматив.
- Достижимость резервной площадки оценивается по кратчайшему пути без учета разворотов и
  энергии на маневр.
- Пределы одного плана: 20 бортов, 400 галсов, участок до 30 км; больше — через оценку
  задания по пакетам.

## Сервис и поставка

- Авторизации и разграничения доступа нет; сервер слушает только `127.0.0.1`. Расчеты
  синхронные, очереди задач с отменой нет.
- Основное хранилище — SQLite. Поддержка PostgreSQL (схема, TLS, пароль из переменной окружения)
  проверена тестовыми двойниками соединения; с настоящим сервером PostgreSQL сервис не
  запускался. Контейнерный запуск (`compose.yaml`) тоже не проверялся.
- Экспорт GeoJSON/KML — для анализа и ГИС, не в формате Geoscan Planner.
- Спутниковая подложка требует своего ключа MapTiler; без интернета работает режим
  «Без подложки».
- Автономная сборка — только 64-битная Windows 10/11, файлы не подписаны; проверена на машине
  сборки в урезанном окружении, не на машине защиты. Интерфейс рассчитан на браузер на ПК.
