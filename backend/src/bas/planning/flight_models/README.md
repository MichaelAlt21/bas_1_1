# Модели полета

`multirotor.py` — время участка при постоянном ветре и воздушной скорости (треугольник скоростей).
`dubins.py` — пути Дубинса (шесть видов, включая петли) с постоянным креном в ветре: развороты —
окружности относительно воздуха, над землей трохоиды; метод виртуальной цели и быстрая оценка.
`fixed_wing.py` — демонстрационная модель самолета 201: соединения поз с прямым заходом на галс,
запуск с катапульты, набор прямо или по спирали, снижение кругами и парашютная посадка со сносом.
Энергомодели нет: ресурс задается бюджетом времени. Описание — `docs/ALGORITHM.md`.
