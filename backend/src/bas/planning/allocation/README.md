# Распределение

Жадное распределение галсов по слотам «борт × вылет» живет в `planning/service.py`: для каждого
направления галсов (0° и 90°, для самолета в ветре еще вдоль и поперек ветра) и каждой из двух
политик. Коптер добавляет галс в конец вылета, самолет вставляет в лучшее место и после
распределения дорабатывает порядок. Отдельный модуль — при дальнейшем развитии алгоритма.
