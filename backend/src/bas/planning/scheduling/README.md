# Расписание

`conflicts.py` проверяет непрерывные сближения участков. Без эшелонов — прежнее правило: ближе
30 м по горизонтали при любых высотах, старт откладывается до конца чужого участка. С эшелонами
или разными высотами пара разведена и при 20 м по высоте (высота линейна внутри участка), а
задержка старта минимальная (конец отрезка конфликтующих задержек). Повторные вылеты начинаются
после замены АКБ или зарядки на ЗУ площадки: одно ЗУ заряжает одну АКБ, очередь по порядку посадки.
